# SkyPaw Kites

Начална страница за фирма, която произвежда хвърчила в България и доставя по целия свят. Сайтът представя готови модели, възможности за персонализиран дизайн, рекламни хвърчила и информация за фирмата.

## Функционалности

- Адаптивен дизайн за desktop, tablet и мобилни устройства.
- Навигация към страниците „Относно“, „Услуги“, „Галерия“ и „Контакти“.
- Самостоятелна страница „Услуги“ с информация за моделите, рекламните поръчки, персонализирания дизайн, размерите и цветовете.
- Самостоятелна галерия с 20 снимки, групирани по изработка, сглобяване и употреба на хвърчила.
- Самостоятелни страници „Относно“ и „Контакти“ с информация за производството, подхода и начините за връзка.
- Карти за модели хвърчила, персонализирани дизайни и рекламни поръчки.
- Анимации при превъртане и мобилно меню.
- Контакт чрез имейл връзка.

## Файлове

- `index.html` — структура и съдържание на страницата.
- `about.html` — представяне и подход на SkyPaw Kites.
- `contacts.html` — начини за връзка и насоки за запитване.
- `gallery.html` — галерия със снимки от работилници, готови хвърчила и тяхната употреба.
- `services.html` — услуги, варианти за персонализиране и насоки за избор на размер.
- `style.css` — стилове и адаптивно оформление.
- `script.js` — мобилно меню, анимации и автоматична година във footer-а.

## Стартиране локално

Отворете `index.html` директно в браузър или стартирайте VS Code Live Server:

1. Отворете папката на проекта във VS Code.
2. Инсталирайте разширението **Live Server**, ако още не е инсталирано.
3. Натиснете с десен бутон върху `index.html` и изберете **Open with Live Server**.

## Публикуване с GitHub Pages

1. Качете файловете в GitHub repository.
2. В repository отворете **Settings → Pages**.
3. Под **Build and deployment** изберете **Deploy from a branch**.
4. Изберете branch `main` и папка `/(root)`, след което натиснете **Save**.
5. След приключване на публикуването GitHub ще покаже адреса на сайта в същата страница.

Проверете и заменете примерните данни за контакт в страниците на сайта — имейл `hello@skypawkites.bg` и телефон `+359 888 123 456`.
